# POLSCI 450 Cohort Hub

A shared public good for the POLSCI 450 cohort: build understanding together, share useful tools, and leave something helpful for the next person.

This is a student-run, unofficial space for original explanations, general R tips, public resources, peer questions, and instructor-authorized worksheet collaboration. It starts with 450A and can grow with the cohort across the 450 sequence.

## Start here

- **Ask or answer a question:** [open an issue](https://github.com/henryzhou825/polsci-450-cohort/issues/new/choose). A clearly stated question is a useful contribution.
- **Share a resource:** suggest a public link and explain what it helps with.
- **Improve a page:** open the file, click the pencil icon, and propose a change. GitHub will guide you through creating a fork if needed and opening a pull request (a proposed edit for review). No terminal required.

Start the shared worksheet answers in [worksheets/main.tex](worksheets/main.tex). For other contributions, organize by topic rather than by assignment. Probability, estimation, inference, regression, and R workflow are useful places to start; add topics as the cohort needs them.

## Keep this a public learning resource

Share work you created specifically for public use. The instructor has authorized public collaboration on the [worksheet workbook](worksheets/README.md), as confirmed by the repository owner. That authorization covers the worksheet material documented there; other course slides, handouts, readings, recordings, transcripts, assessment prompts, assignment datasets, and solutions require separate permission. Keep graded-assignment collaboration in the channels permitted by the course. The current syllabus governs collaboration and AI use.

Use public links instead of uploading someone else's material. Cite sources, make uncertainty visible, and get permission before sharing another person's work or identifying details.

See [Contributing](CONTRIBUTING.md) for the short guide. Original contributions are available under the [MIT license](LICENSE); linked resources retain their own licenses, and instructor-authored worksheet text has its own [attribution and license scope](worksheets/LICENSE.md).

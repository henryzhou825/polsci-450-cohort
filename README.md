# POLSCI 450 Cohort Hub

A shared public good for the POLSCI 450 cohort: build understanding together, share useful tools, and leave something helpful for the next person.

This is a student-run, unofficial space for original explanations, general R tips, public resources, and peer questions. It starts with 450A and can grow with the cohort across the 450 sequence.

## Start here

- **Ask or answer a question:** [open an issue](https://github.com/henryzhou825/polsci-450-cohort/issues/new/choose). A clearly stated question is a useful contribution.
- **Share a resource:** suggest a public link and explain what it helps with.
- **Improve a page:** open the file, click the pencil icon, and propose a change. GitHub will guide you through creating a fork if needed and opening a pull request (a proposed edit for review). No terminal required.

## Find your way around

| Area | What belongs here |
| --- | --- |
| [Concept notes](notes/README.md) | Original explanations, assumptions, intuition, and independent examples |
| [R tips](r-tips/README.md) | General workflow advice and small reproducible troubleshooting examples |
| [Examples](examples/README.md) | Standalone demonstrations using synthetic or openly licensed data |
| [Public resources](resources.md) | Annotated links to freely accessible references and documentation |
| [Note template](templates/concept-note.md) | A starting point for a new explanation |

Organize contributions by topic rather than by assignment. Probability, estimation, inference, regression, and R workflow are useful places to start; add topics as the cohort needs them.

## Keep this a public learning resource

Share work you created specifically for public use. Do not post course slides, handouts, readings, recordings, transcripts, assessment prompts, assignment datasets, or solutions. Keep assignment-specific collaboration in the channels permitted by the course. The current syllabus governs collaboration and AI use.

Use public links instead of uploading someone else's material. Cite sources, make uncertainty visible, and get permission before sharing another person's work or identifying details.

See [Contributing](CONTRIBUTING.md) for the short guide. Original contributions are available under the [MIT license](LICENSE); linked resources retain their own licenses.

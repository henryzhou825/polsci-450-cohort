# R tips

Share small, general tips that help someone get unstuck: project paths, package installation, data types, plotting, debugging, or reporting results.

For a troubleshooting example, include:

1. What you expected and what happened, including the exact error message.
2. The smallest code example that reproduces it, using synthetic or built-in data.
3. The fix and a short explanation of why it works.
4. Your R version and relevant package versions when they affect the result.

Keep course datasets, assignment code, credentials, and personal file paths out of examples. Start with the [public resources](../resources.md) or [ask a general R question](https://github.com/henryzhou825/polsci-450-cohort/issues/new/choose).
